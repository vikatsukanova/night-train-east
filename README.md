# Night Train East

A calm, third-person browser game about riding a train through the night. The P0 build opens on a lit carriage greybox.
Use Node 24 (`nvm use`) and run `corepack enable`.
Run `pnpm install --frozen-lockfile` and `pnpm dev` to start locally.
Run `pnpm verify` for the full local check or `pnpm build && pnpm preview` to serve the production build.
Read the [PRD](docs/PRD.md), [architecture](docs/ARCHITECTURE.md), [rendering plan](docs/RENDERING.md), and [CI/CD guide](docs/CICD.md).
[Play on GitHub Pages](https://vikatsukanova.github.io/night-train-east/).
